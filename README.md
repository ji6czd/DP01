## 対応していること

- DAISY 2.02で確認しました。
- 見出し単位での移動に対応しています。
- フレーズ(クリップ)単位での移動に対応しています。
- 再生速度の変更に対応しています。
- 見出しレベルの変更に対応しています。
- 操作の合図(モールス信号)に対応しています。
- 最後に再生した位置を記憶して、次回起動時にそこから再生を再開します。
- フレーズ単位での移動に対応しています。
- 今のところMP3ファイルのみ対応しています。

## 対応ハードウェア

M5Stack Cardputer ADVを対象としています。
